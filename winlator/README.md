# Доработки Winlator

Два патча поверх официального Winlator 11.2, применяются по порядку:

1. `home-screen-shortcut.patch` — иконки игр на главном экране Android.
2. `frame-generation.patch` — генерация промежуточных кадров внутри Winlator.

## Иконки на главном экране

Патч добавляет пункт «Добавить на главный экран» в меню файла (файловый менеджер контейнера) и в меню ярлыка (раздел «Ярлыки»). На главном экране Android появляется иконка, которая запускает программу сразу, без меню Winlator.

## Генерация кадров

Включается в игре: боковое меню → «Эффект экрана» → «Генерация кадров» (x2, x3 или x4). Настройка запоминается.

Как это работает:

- Все кадры игры и так проходят через отрисовщик Winlator, поэтому захват экрана не нужен.
- Пока игра выдаёт кадры ровно и не чаще половины частоты экрана, отрисовщик переходит на такт экрана: на каждый кадр игры он сначала показывает промежуточные кадры, затем настоящий.
- Промежуточный кадр строится по полю движения между двумя последними кадрами игры. Поле ищется на уменьшенных копиях кадров, от грубого уровня к точному.
- Пиксели, одинаковые в обоих кадрах, не трогаются: так HUD и текст остаются чёткими.
- Курсор рисуется поверх готового кадра и не участвует в расчёте.
- Качество (три ступени) подбирается само: если расчёт занимает больше половины периода экрана, ступень понижается.

Если игра идёт быстрее половины частоты экрана, генерация не включается. Ограничить частоту кадров игры можно в настройках DXVK контейнера.

Добавленная задержка — половина интервала между кадрами игры плюс время до ближайшего такта экрана. На устройстве это пока не измерялось.

Шейдеры проверены в headless Chromium (WebGL2, тот же GLSL ES 3.00) на синтетических кадрах с известным правильным промежуточным кадром:

| Сцена, 1280×720 | Генерация | Простое смешивание |
| --- | --- | --- |
| Панорама 12 пикселей за кадр | 21,5 дБ | 15,8 дБ |
| Панорама 90 пикселей за кадр | 17,7 дБ | 12,3 дБ |
| Неподвижный фон, движется объект | 34,8 дБ | 28,9 дБ |
| Кадр на четверти пути (режим x4) | 21,7 дБ | 15,1 дБ |

Цифры — PSNR, больше значит ближе к правильному кадру. Тестовая сцена намеренно жёсткая: много мелких контрастных фигур и тонких линий. Проверку можно повторить:

```
node tools/framegen-test.js <winlator-app>/app/src/main/assets/framegen <папка для картинок> '[{"name":"pan","w":1280,"h":720,"pan":[12,4],"obj":[-20,6],"t":0.5,"pipeline":"quality","base":8,"save":true}]'
```

На реальном устройстве генерация ещё не запускалась.

## Исходный код и сборка

Исходный код Winlator: <https://github.com/brunodev85/winlator-app> (лицензия LGPL-2.1). Патчи сделаны поверх коммита `ecd5ab2980de79eb955621cef26a3b4672013875` и распространяются на тех же условиях.

Нужны JDK 17 или новее и Android SDK с NDK 24.0.8215888 и CMake 3.22.1.

```
git clone https://github.com/brunodev85/winlator-app
cd winlator-app
git checkout ecd5ab2980de79eb955621cef26a3b4672013875
git apply ../home-screen-shortcut.patch
git apply ../frame-generation.patch
./gradlew :app:assembleDebug
```

Чтобы сборка ставилась поверх предыдущей, перед сборкой скопируйте `app/debug.keystore` из этого репозитория в `~/.android/debug.keystore`.

## Что изменено в коде

- `FrameGenerator` — такт, поиск движения и вывод промежуточных кадров; шейдеры лежат в `assets/framegen`.
- `GLRenderer`, `EffectComposer` — сцена может рисоваться в текстуру и без курсора.
- `ScreenEffectDialog` — настройка и строка состояния генерации.
- `HomeScreenShortcut` — создаёт закреплённый ярлык через `ShortcutManager`.
- `ShortcutLauncherActivity` — принимает нажатие на иконку, проверяет, что контейнер и файл на месте, и запускает `XServerDisplayActivity`. Если чего-то нет, открывает обычный экран Winlator.
- В меню файла и ярлыка добавлен новый пункт; строки переведены на русский и португальский.

Имя пакета оставлено `com.winlator`: на нём завязаны пути внутри системы Winlator. Поэтому эта сборка ставится вместо официальной, а не рядом с ней.
