# FrameGen Mobile

Генерация кадров для Android-игр без root: приложение захватывает экран, строит промежуточные кадры и показывает их в окне поверх игры.

Сейчас в репозитории тестовая сборка 0.1 (этап 0 из ТЗ). Она:

- показывает характеристики устройства: чип, графику, версию Android, частоты экрана, Vulkan;
- проверяет захват экрана и окно поверх игры, в том числе не попадает ли окно в собственный захват;
- считает настоящие кадры игры и время обработки;
- умеет два режима с картинкой: «Зеркало» (показ захваченного кадра) и «Смешивание x2» (промежуточный кадр — смесь двух соседних).

Оценки движения в этой сборке ещё нет, поэтому промежуточные кадры размытые.

## Сборка

Нужны JDK 17 или новее и Android SDK (platform 35, build-tools 35.0.0). Путь к SDK задаётся в `local.properties` (`sdk.dir=...`) или в переменной `ANDROID_HOME`.

```
./gradlew :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Все сборки подписываются ключом `app/debug.keystore`, поэтому новая версия ставится поверх старой.

## Устройство кода

- `MainActivity` — экран с отчётом, разрешениями, запуском и журналом.
- `CaptureService` — служба: захват экрана, окно поверх игры, кнопка управления.
- `GlPipeline` — графический поток: отсев повторных кадров, хранение двух последних, вывод.
- `PassthroughService` — служба специальных возможностей; нужна только для того, чтобы окно пропускало касания.
- `DeviceReport`, `Diag` — отчёт об устройстве и журнал запуска.
